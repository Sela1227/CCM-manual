## 個管師日常工作對應

各指標對應到個管師日常追蹤工作，可幫助提升達標率：

| 指標類型 | 個管師可介入時機 |
|---------|---------------|
| **檢查完整率**（如肝癌影像追蹤、PSA 檢測、CT 檢查）| 收案時建立追蹤排程；治療前 1 個月內提醒病人完成檢查 |
| **治療時效**（如直腸癌 6 週內治療、放療 63 天內完成）| 每週看治療進度；接近時限提醒醫師與病人 |
| **手術品質**（如 R0 切除、淋巴結 ≥12/15 顆）| 跟刀後核對病理報告完整性；不完整時請病理科補充 |
| **輔助治療率**（如術後化療、輔助放療）| 術後 4 週開始密集電訪追蹤；確認回診與治療安排 |
| **死亡率（負向）** | 高風險個案（高齡、合併症、營養差）優先列管；早期介入安寧/支持治療討論 |
