# F5. 癌症三大治療方式基礎

> 這一節是給新人建立「整體概念地圖」用的，不是詳細的醫學教科書。
> 讀完的目標：當醫師說「這個病人要做術後輔助化療」，你知道大概在說什麼、個管師要關注什麼。

---

## 壹、手術治療

### 手術的目的

癌症手術有三種不同的目的，性質完全不同：

| 目的 | 說明 | 舉例 |
|------|------|------|
| **根治性手術** | 切除腫瘤，目標是治癒 | 早期肺癌肺葉切除、乳癌全切或保乳手術 |
| **姑息性手術** | 不以治癒為目標，減輕症狀或維持功能 | 腸阻塞的造口手術、骨轉移的固定手術 |
| **診斷性手術** | 取組織做病理確診 | 淋巴結切片、開胸取樣 |

!!! tip "個管師要知道的"
    當治療計畫書上寫的是「姑息性手術」，病人期待的卻是「治好」，這是衛教溝通的重點。個管師需要協助釐清病人對手術目的的理解。

### 常見術式類型

| 術式 | 說明 |
|------|------|
| **開放性手術** | 傳統大切口，視野最清楚，適合複雜病灶 |
| **腹腔鏡/胸腔鏡（微創）** | 小切口，恢復快，傷口疼痛較輕 |
| **達文西機器手臂** | 腹腔鏡的進階版，精準度更高 |
| **內視鏡切除（EMR/ESD）** | 無切口，透過消化道直接切除，適合早期黏膜癌 |

### 手術邊緣（Margin）

術後病理報告會說明手術邊緣是否乾淨：

| 名稱 | 意義 | 後續可能 |
|------|------|---------|
| **R0** | 邊緣無殘存癌細胞（完全切除）| 最佳結果 |
| **R1** | 顯微鏡下可見殘存癌細胞 | 可能需追加放療 |
| **R2** | 肉眼可見殘存腫瘤 | 手術不完整 |

!!! note "指標連結"
    R0 切除率是多個癌別的品質指標（胃癌、食道癌、肝癌、胰臟癌）。個管師追蹤手術結果時需關注病理報告的邊緣狀態。

### 個管師在手術前後的角色

**術前：**
- 確認病人了解手術目的和風險
- 確認術前評估（功能狀態 ECOG、心肺功能）是否完成
- 確認多專科團隊討論過（尤其大手術）

**術後：**
- 追蹤恢復狀況（傷口、進食、活動）
- 確認病理報告已取得並溝通給病人
- 依術後分期確認是否需要輔助治療
- 提醒回診和影像追蹤時程

## 貳、化學治療

### 化療的目的

| 目的 | 名稱 | 說明 |
|------|------|------|
| 以治癒為目標（術後） | **輔助性化療（Adjuvant）** | 手術後給，消滅可能殘存的微小轉移 |
| 手術前縮瘤 | **前導性化療（Neoadjuvant）** | 先給化療讓腫瘤縮小，再做手術 |
| 搭配放療增效 | **同步化放療（CCRT）** | 化療讓腫瘤對放療更敏感 |
| 控制疾病（無法治癒） | **姑息性化療（Palliative）** | 延緩疾病進展、維持生活品質 |

### 化療給藥概念

**Cycle（療程/週期）**

化療不是每天打，而是「打幾天、休息幾天」為一個 cycle，讓身體有時間恢復。常見週期：

| 週期 | 說明 |
|------|------|
| **Q3W**（每 3 週一次） | 最常見，例如 Carboplatin + Paclitaxel 每 21 天一次 |
| **Q2W**（每 2 週一次） | FOLFOX 等方案 |
| **Weekly**（每週一次） | 劑量較低，副作用分散 |
| **D1-5 Q4W** | 連打 5 天，休息 23 天 |

**口服化療**

部分化療藥物有口服劑型，病人在家自行服藥：

| 藥物 | 常用癌別 | 注意事項 |
|------|---------|---------|
| Capecitabine（截瘤達）| 大腸癌、乳癌 | 飯後服用，注意手足症候群 |
| Ufur（愛福錠）| 大腸癌 | 服滿半年為大腸癌完治標準之一 |
| Erlotinib（得舒緩）| 肺癌（EGFR+）| 空腹服用，注意皮疹 |
| Exemestane（諾曼癌素）| 乳癌（停經後）| 荷爾蒙治療藥，每日一顆 |

!!! warning "口服化療的追蹤重點"
    病人在家自行服藥，副作用出現時可能不會主動回報。個管師追蹤電話要主動問：「有沒有手腳脫皮或麻麻的感覺？」「有沒有腹瀉超過一天？」

### 輸液途徑

| 途徑 | 說明 | 個管師注意 |
|------|------|-----------|
| **周邊靜脈注射** | 一般手臂血管 | 多次使用後血管易損傷，評估是否需置管 |
| **Port-A（人工血管）** | 皮下埋入裝置，長期使用 | 每次化療前確認 Port-A 功能，定期沖洗 |
| **PICC** | 手臂置入中心靜脈導管 | 注意感染和移位，日常照護衛教 |

### 化療常見副作用速查

!!! tip "副作用分為「何時開始」"
    不同副作用出現的時間點不同，有助於提前預告病人。

| 副作用 | 通常出現時間 | 個管師追蹤重點 |
|--------|-----------|--------------|
| **噁心嘔吐** | 化療當天至 3 天內 | 止吐藥有沒有服用？飲食狀況？ |
| **骨髓抑制**（白血球/血小板低下）| 化療後 7–14 天（最低點）| 有沒有發燒？（發燒 > 38°C 是緊急狀況）|
| **掉髮** | 化療後 2–4 週 | 提前衛教、心理支持 |
| **口腔黏膜炎** | 化療後 3–10 天 | 口腔清潔衛教，嚴重時影響進食 |
| **手足症候群** | 口服化療累積後 | 皮膚脫皮、紅腫、疼痛，影響日常生活 |
| **周邊神經病變** | 累積劑量後 | 手腳麻木、影響拿取物品，需告知醫師評估 |
| **腎毒性** | Cisplatin 相關 | 確認水分補充足夠，追蹤腎功能 |

**需要立刻回診的警示症狀：**
- 發燒 > 38°C（可能是感染性嗜中性球低下，有生命危險）
- 嚴重嘔吐無法進食超過 24 小時
- 嚴重腹瀉（一天超過 6 次）
- 胸痛或呼吸困難

## 參、放射線治療

### 放療的目的

| 目的 | 說明 |
|------|------|
| **根治性放療** | 單獨以放療達成治癒，如早期鼻咽癌、前列腺癌 |
| **術後輔助放療** | 手術後追加照射，降低局部復發 |
| **CCRT（同步化放療）** | 放療同時給低劑量化療，增加放療效果 |
| **姑息性放療** | 緩解疼痛（骨轉移）、壓迫症狀（腦轉移）|

### 放療的單位和概念

**劑量單位：** Gy（戈瑞），100 cGy = 1 Gy

**Fraction（分次）：** 放療通常分多次給，每次叫一個 fraction。

| 概念 | 說明 | 舉例 |
|------|------|------|
| **常規分次** | 每天 1 次，每週 5 天，共 5–7 週 | 頭頸癌：70 Gy / 35 次 |
| **低分次** | 每次劑量較高，總次數少 | 攝護腺癌：60 Gy / 20 次 |
| **SBRT/SABR** | 極少次、極高劑量，精準照射 | 早期肺癌：54 Gy / 3 次 |
| **Brachytherapy（近接治療）** | 放射源放入體內照射 | 子宮頸癌的標準治療之一 |

!!! note "個管師會遇到的名詞"
    「63 天完成放療」是子宮頸癌的品質指標之一。個管師追蹤放療進度時，需注意放療開始日期和預計完成日期。

### 放療技術名詞

| 縮寫 | 全名 | 說明 |
|------|------|------|
| **3D-CRT** | 3D適形放療 | 傳統高精準放療 |
| **IMRT** | 強度調控放療 | 調整各方向劑量，保護正常組織 |
| **IGRT** | 影像導引放療 | 每次治療前拍攝影像確認位置 |
| **SBRT** | 立體定位放療 | 少次高劑量，精準打小腫瘤 |
| **CCRT** | 同步化放療 | 化療 + 放療同時進行 |

### 放療副作用：依照射部位

**急性副作用（治療中和治療後短期）：**

| 照射部位 | 常見急性副作用 | 個管師衛教重點 |
|---------|-------------|--------------|
| **頭頸部** | 口腔黏膜炎、吞嚥困難、皮膚反應、口乾 | 口腔清潔、軟食/流質、皮膚保護 |
| **胸部** | 食道炎（吞嚥痛）、皮膚炎、放射性肺炎（晚期）| 飲食調整、皮膚保護，出現喘要回診 |
| **腹部/骨盆** | 腹瀉、噁心、頻尿/尿道炎 | 飲食清淡、保持水分 |
| **全身** | 疲倦（幾乎所有病人都有）| 規律休息，不需停治療 |

**慢性副作用（治療結束數個月至數年後）：**

| 部位 | 慢性副作用 |
|------|-----------|
| 頭頸部 | 永久性口乾（唾液腺損傷）、齲齒、顎骨壞死（ORN）|
| 胸部 | 肺纖維化、心臟毒性 |
| 骨盆 | 直腸炎、膀胱炎、性功能影響、淋巴水腫 |

!!! warning "放療後長期追蹤提醒"
    部分慢性副作用在治療結束後才慢慢出現，個管師長期追蹤電話中應主動詢問（不是等病人說）。例如：「口腔有沒有一直很乾？牙齒有沒有新的問題？」

### 個管師在放療期間的角色

| 時機 | 個管師任務 |
|------|-----------|
| **放療前** | 說明療程長度、副作用預期、飲食準備 |
| **放療中（每週追蹤）** | 確認副作用程度、是否影響進食和體重、需不需要營養師介入 |
| **放療完成後** | 說明「副作用通常還會持續 2-4 週後漸消退」、安排後續追蹤影像 |

## 肆、三種治療的組合使用

實際臨床上，三種治療常常組合使用。個管師需要能看懂治療計畫書上的組合：

| 組合 | 名稱 | 典型應用 |
|------|------|---------|
| 手術 + 術後化療 | 輔助化療 | 大腸癌 II-III 期、胃癌 II-III 期 |
| 手術 + 術後放療 | 輔助放療 | 乳癌全切後淋巴陽性 ≥4 顆 |
| 化療 + 放療同時 | CCRT | 子宮頸癌、頭頸癌、食道癌、直腸癌 |
| 前導化療 → 手術 | 術前化療 | 局部晚期食道癌、胃癌、乳癌 |
| 化療 → 手術 → 化療 | 夾心療法 | 部分胰臟癌、胃癌方案 |

## 伍、個管師常用問題清單

電話追蹤時，依不同治療方式快速確認：

**手術後（前 4 週）：**
- 傷口有沒有紅腫、滲液？
- 飲食恢復狀況？體重有沒有明顯下降？
- 活動能力？
- 病理報告有沒有跟醫師討論過？
- 下一步治療計畫清楚嗎？

**化療中：**
- 這個 cycle 有沒有發燒？（>38°C 要立刻就醫）
- 噁心嘔吐影響進食幾天？
- 手腳有沒有麻木或脫皮？
- 體力怎麼樣？

**放療中：**
- 吃東西有沒有困難？（頭頸、食道）
- 皮膚有沒有脫皮？
- 有沒有腹瀉？（腹部/骨盆）
- 疲倦程度影響日常生活嗎？
