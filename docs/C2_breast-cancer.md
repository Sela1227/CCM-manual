## 一、疾病概述

### 流行病學

- 台灣女性癌症發生率：第一位
- 本院每年新案數：約（待補充）例
- 好發年齡：45-69 歲

### 危險因子

- 年齡增加
- 家族史（尤其一等親）
- BRCA1/BRCA2 基因突變
- 初經早、停經晚
- 未生育或晚生育
- 荷爾蒙補充療法
- 肥胖
- 飲酒

### 臨床治療分群

> 💡 **乳癌的第一個分岔點就是這裡**——ER/PR 跟 HER2 的組合決定整個治療主軸。

| 臨床治療分群 | 定義 | 治療主軸 |
|---|---|---|
| **HR+/HER2−** | ER 或 PR 陽性、**HER2 陰性** | 內分泌治療 ± 化療 ／ CDK4/6 抑制劑 |
| **HER2+** | **HER2 陽性，不論 HR 狀態** | 抗 HER2 治療 ± 化療；**HR+ 者另加內分泌治療** |
| **三陰性（TNBC）** | ER−、PR−、HER2− | 化療；部分高風險個案合併免疫或其他治療 |

!!! info "為什麼不用 Luminal A／B 分？"
    你會在病歷和文獻上看到 **Luminal A／Luminal B／HER2-enriched／Basal-like**——那是**分子內在分型（intrinsic subtype）**，原本要靠**基因表現分析**才能定。

    臨床上用 ER／PR／HER2／Ki-67 這四個 **IHC 染色**去推，是**替代分型（surrogate）**，**不等於**真正的分子分型：

    - **Ki-67 的切點各家不同、跨實驗室一致性有限**——同一顆腫瘤在不同醫院可能被分到不同格
    - **Luminal B 跟 HER2+ 會重疊**——HR+/HER2+ 該放哪一格？（答案：**走 HER2+ 的路，另加內分泌治療**）

    **本手冊以影響治療決策的 HR／HER2 分群為主**，Luminal A／B 當生物學概念理解就好，不用拿它做判斷。

> 📋 ER/PR/HER2/Ki-67 的判讀見 [F2 分子與病理檢測](F2_pathology.md)。

## 二、診斷與分期

### 診斷流程

```
發現乳房異常（自我檢查/篩檢）
        ↓
    乳房攝影/超音波
        ↓
    粗針切片（Core biopsy）
        ↓
    病理報告 + 分子檢測（ER/PR/HER2/Ki-67）
        ↓
    分期檢查
        ↓
    MDT 討論治療計畫
```

### 檢查項目

!!! danger "🔴 不是每個人都要做全身影像"
    **低風險、無症狀的早期乳癌，不建議常規做 CT／骨掃描／PET 篩查遠端轉移**——做了不會改善預後，卻會增加輻射、偽陽性與焦慮。

    要不要做遠端分期，**依期別、症狀與高風險特徵決定，由醫師判斷**。個管師的任務是**確認醫師開的都做完了**，不是**確認清單上每一項都做**。

#### 所有個案的基本項目

| 檢查 | 目的 |
|------|------|
| 乳房攝影／超音波 | 偵測腫塊、鈣化；評估腫塊性質 |
| **粗針切片** | 確定診斷（**不是細針，細針無法判 ER/PR/HER2**）|
| 病理：**ER／PR** | 荷爾蒙受體狀態 → 決定要不要內分泌治療 |
| 病理：**HER2** | HER2 表現狀態 → 決定要不要抗 HER2 標靶 |
| 病理：**Ki-67、Grade** | 增殖指數與分化程度 → 影響化療決策 |
| **腋下淋巴結評估** | 超音波 ± 細針／粗針；決定手術方式 |

#### 依期別及臨床需要（醫師判斷，不是人人都做）

| 檢查 | 什麼時候會做 |
|------|------------|
| 胸腹部 CT | 期別較高、有症狀、或高風險特徵 |
| 骨掃描 或 PET-CT | 同上；骨痛、鹼性磷酸酶升高等 |
| 乳房 MRI | 多發病灶疑慮、緻密乳房、術前治療評估、植入物 |
| 腦部影像 | **有神經症狀時**（早期乳癌不常規做）|

> 💡 **個管師常見的誤會**：看到病人「只做了乳房攝影和切片，沒做 CT」就以為漏了——**那可能正是對的**。有疑問問醫師，不要自己催檢查。

### TNM 分期（AJCC **第 8 版**）

> 📋 **版本說明**：乳癌**尚未釋出 AJCC Version 9，第 8 版就是現行版**——不需要也不應該改標成第 9 版。全站版本對照的權威源見 [C0 → 分期系統版本對照表](C0_general.md#分期系統版本對照ajcc-已改逐部位滾動更新)。

**簡化說明（解剖分期）：**

| 期別 | 大致情況 |
|------|---------|
| 0 期（原位癌） | 未侵犯，預後極佳 |
| I 期 | ≤ 2cm，無淋巴轉移 |
| II 期 | 2-5cm 或有腋下淋巴轉移 |
| III 期 | 局部晚期，較大或多處淋巴轉移 |
| IV 期 | 有遠端轉移 |

> ⚠️ **乳癌第 8 版另有「預後分期（Prognostic Stage）」**——把 ER/PR/HER2/Grade（必要時加基因檢測結果）納入，跟上表的解剖分期可能不同期別。**病理報告與病歷寫的期別要確認是哪一種**，跟病人說明前先問清楚。
>
> **個管師不判期別**——實際期別以病理報告與主治醫師判定為準。完整分期表因 AJCC 版權不收錄（見 [C0](C0_general.md#怎麼查最新狀態)）。
>
> 💡 ER/PR/HER2/Ki-67 的判讀見 [F2 分子與病理檢測](F2_pathology.md)；風險分層與 CDK4/6 抑制劑適應症見本檔 [CDK4/6 抑制劑](#cdk46-抑制劑hrher2--重點藥物)。

## 三、治療指引

### 治療決策地圖：先開刀，還是先治療？

!!! danger "🔴 「術前治療 = 三期才做」是過時的觀念"
    現代乳癌**不是只有 III 期才考慮術前治療**。**HER2+ 與 TNBC 的部分第二期個案**也會先做術前治療——因為**病理反應（pCR vs residual disease）會改變後續路徑**。

```
              新診斷侵襲性乳癌
                     │
      ┌──────────────▼──────────────┐
      │ 確認 HR／HER2、腫瘤大小、淋巴結 │
      └──────────────┬──────────────┘
                     │
      ┌──────────────▼───────────────────┐
      │ HER2+ 或 TNBC，且腫瘤較大／淋巴結陽性？│
      └──────┬────────────────────┬───────┘
            YES                   NO
             │                     │
    優先評估術前全身治療      手術優先 或 依團隊討論
             │                     │
             └──────────┬──────────┘
                        │
              ┌─────────▼──────────┐
              │ 手術 → 病理報告出爐 │
              └─────────┬──────────┘
                        │
          ┌─────────────▼─────────────┐
          │  pCR（完全反應）           │
          │      vs                    │
          │  residual disease（殘存）  │  🔑 這一格決定後續
          └─────────────┬─────────────┘
                        │
        決定後續：標靶／化療／內分泌／放療
```

!!! warning "這張圖是「理解用」，不是「決策用」"
    **個管師不做治療決策**（見 [C0 → 個管師不做的事](C0_general.md#個管師不做的事)）。

    **你不必背療程，但一定要知道這件事**：**術前治療後的病理反應會改變後續治療**——所以

    | 你要做的 | 為什麼 |
    |---------|--------|
    | **術前治療者：確認腫瘤與陽性淋巴結已標記** | 治療後腫瘤可能縮到看不見，沒標記手術找不到位置 |
    | **術後主動追病理報告：pCR 還是有殘存** | 這一格決定後續治療，**病人會問「開完刀是不是就好了」** |
    | **不要跟病人說「腫瘤消失了就是治好了」** | pCR 是好消息，但**後續治療通常還是要做完** |

    ⚠️ **本圖待醫師團隊審稿確認**。

### 治療原則

| 期別 | 主要治療 |
|------|---------|
| 早期（I-II） | 手術 → 輔助治療（依臨床治療分群）；**HER2+／TNBC 的部分個案會先做術前治療** |
| 局部晚期（III） | 術前治療 → 手術 → 輔助治療（**依病理反應調整**）|
| 轉移性（IV） | 全身性治療為主 |

### 手術方式

#### 乳房手術

| 方式 | 一般使用情境 |
|------|------------|
| **乳房保留手術（BCS）** | 腫瘤範圍適合、乳房與腫瘤比例可接受、**且能接受術後放療** |
| **全乳切除** | 腫瘤較大／多發／無法達成安全切緣／不能接受放療／**病人選擇** |

#### 腋下手術

| 方式 | 一般使用情境 |
|------|------------|
| **前哨淋巴結切片（SLNB）** | 多用於**臨床腋下淋巴結陰性（cN0）**的早期乳癌 |
| **腋下淋巴結廓清（ALND）** | **依 cN 狀態、陽性淋巴結負荷、手術方式、術前治療反應、預定放療範圍綜合決定** |

!!! danger "🔴 前哨淋巴結陽性 ≠ 一定要做腋下廓清"
    這是很常見的誤解。**部分接受乳房保留手術、cN0、且僅 1–2 顆前哨淋巴結陽性的病人，可以省略完整腋下廓清**（Z0011 長期結果支持：適當選擇的病人不做 ALND 並不降低整體存活）。

    省略 ALND 能大幅降低**淋巴水腫**風險——這對病人的長期生活品質影響很大。

    **個管師要做的**：

    | 記錄什麼 | 為什麼 |
    |---------|--------|
    | **cN 狀態**（術前臨床淋巴結）| 決定走 SLNB 還是直接 ALND 的起點 |
    | **SLN 陽性顆數** | 1–2 顆 vs ≥ 3 顆，後續處理不同 |
    | **是否接受術前治療** | 術前治療後的腋下處理規則不一樣 |
    | **最終腋下處理方式** | 影響放療範圍與淋巴水腫衛教強度 |

    ⚠️ **不自行判定病人需不需要廓清**——那是外科與 MDT 的決定（見 [C0 → 個管師不做的事](C0_general.md#個管師不做的事)）。

### 輔助治療

| 臨床治療分群 | 輔助治療主軸 |
|------|-------------|
| **HR+/HER2−** | 內分泌治療 **5–10 年** ± 化療（依復發風險）；**高風險者可能加 CDK4/6 抑制劑**（見下節）|
| **HER2+** | 抗 HER2 標靶（Trastuzumab ± Pertuzumab）+ 化療；**HR+ 者另加內分泌治療** |
| **三陰性（TNBC）** | 化療 ± 免疫治療 |

> ⚠️ **要不要加化療不是看分群就決定**——HR+/HER2− 的化療決策還要看腫瘤大小、淋巴結、Grade、Ki-67，**必要時做多基因表現風險檢測**（見 [六、常見問題](#q-什麼情況會做乳癌多基因表現風險檢測上表-②)）。

### 放射治療

| 情境 | 一般原則 |
|------|---------|
| **乳房保留手術後** | **通常需要放療**——它是乳房保留治療的標準組成。**極少數年長、低風險、HR+、淋巴結陰性並接受內分泌治療的個案**，可由乳癌團隊評估是否省略 |
| **全乳切除後** | **依腫瘤大小、淋巴結狀態、切緣、皮膚／胸壁侵犯、術前治療反應等綜合評估**，不是「高風險就一定要」這麼簡單 |

> 💡 **個管師實務**：病人問「我一定要放療嗎？」——**不要回答「保乳就一定要」**。正確說法是「**保乳後放療是標準做法，但你的情況要請醫師評估**」，然後把這個問題帶回去。
>
> 🔗 **重建與放療要一起討論**：計畫做乳房重建的病人，**重建方式與時機會受放療影響**——術前就要跨科討論過，不能等放療要開始才發現衝突。

### CDK4/6 抑制劑（HR+/HER2- 重點藥物）

> 📌 **本節的定位**：CDK4/6 抑制劑是 **HR+/HER2− 乳癌**的重點藥物，也是個管師事前審查最常處理的藥。
>
> **本節只寫個管師每天用得到的**：什麼時候會遇到、三藥核心差異、🚩 紅旗副作用、事審時序與 checklist。
> **完整健保條文、試驗收案細節、副作用百分比、監測排程**收在各段的「📋 展開」折疊區裡——**條文的權威源是 [drug-lookup 抗癌藥物速查](../drug-lookup/){target=_blank}**（健保署原文），本節寫的是怎麼用。

#### 什麼時候會遇到 CDK4/6 抑制劑

| 情境 | 你會做什麼 |
|------|----------|
| **HR+/HER2− 早期乳癌、術後、淋巴結陽性高風險** | 醫師評估 **abemaciclib 輔助**（健保 9.107）→ **你要跑事審**（時序最容易卡）|
| **HR+/HER2− 早期、N0 但高風險** | 可能討論 **ribociclib 輔助**（**自費**）→ **你要協助財務評估與溝通** |
| **HR+/HER2− 轉移性** | **palbociclib 或 ribociclib**（健保 9.72）→ **你要留意二選一與終生 24 個月上限** |
| **任何 CDK4/6i 使用中** | **副作用追蹤 + 🚩 紅旗辨識** |

> ⚠️ **HER2 陽性的病人不會用到這節**——他們走抗 HER2 標靶（見 [輔助治療](#輔助治療)）。

CDK4/6 抑制劑是 HR+/HER2- 乳癌主力標靶。三種藥在健保版圖上不重疊——務必先分清楚「輔助治療」vs「轉移性」走哪一條。

#### 三藥對照速記

| 學名 | 商品名 | 健保條文 | 給付情境 | 副作用主軸 |
|---|---|---|---|---|
| **abemaciclib** | 捷癌寧 Verzenio | **9.107** | **早期輔助**（淋巴結陽性高風險）| 腹瀉（腸胃道）|
| **palbociclib** | 愛乳適 Ibrance | **9.72** | **轉移性** | 嗜中性球低下（血液）|
| **ribociclib** | 擊癌利 Kisqali | **9.72** | **轉移性**；輔助 = **自費**（NATALEE 試驗、台灣健保未給付）| 血液 + QT 延長 + 肝功能 |

**個管師記法**：捷癌寧顧腸胃、愛乳適顧血球、擊癌利顧血球+心電圖+肝。

> 💡 **核心觀念**：abemaciclib 守「**輔助**」（健保 9.107、限淋巴結陽性高風險）；palbociclib / ribociclib 守「**轉移性**」（健保 9.72）。
>
> ℹ️ **N0 高風險病人想用輔助 CDK4/6i**：**目前已具大型第三期輔助治療證據的 CDK4/6 抑制劑為 ribociclib**（NATALEE，納入部分高風險 N0 的第二、三期 HR+/HER2− 族群）；**台灣健保未給付輔助、需自費**——詳見下段並排對照。
>
> ⚠️ **abemaciclib 在轉移性「有藥證但無健保」**——轉移性想用健保 CDK4/6i，走 9.72 的 palbo 或 ribo。

#### 輔助治療：abemaciclib（健保）vs ribociclib（自費）

> 兩藥都用於早期乳癌**術後輔助**、但**收案族群、療程、健保狀態完全不同**——個管師務必先分清楚再協助送審/諮詢。

##### 兩藥並排對照

| 面向 | **abemaciclib（捷癌寧）** | **ribociclib（擊癌利）** |
|---|---|---|
| 試驗 | monarchE | NATALEE |
| **收案淋巴結** | **僅淋巴結陽性**（pN1 以上、含 N1mi）| 淋巴結陽性 **+ 高風險 N0** |
| **每日劑量（輔助）** | 150 mg BID | **400 mg**（與轉移性 600 mg 不同）|
| **療程** | **2 年** | **3 年** |
| 搭配內分泌治療 | AI 或 tamoxifen | **僅 AI（letrozole/anastrozole）**；**禁與 tamoxifen 併用**（QT 風險）|
| 停經前需加 GnRH | 視內分泌治療而定 | **須加** GnRH（如停經針）|
| **副作用主軸** | 腹瀉（80–90%）| 血液（嗜中性球低下 62.8%）+ QT 延長 + 肝功能 |
| **TFDA 藥證（輔助）** | ✓ | 🔴 **本手冊未完成查證**（見下方警語）|
| **台灣健保（輔助）** | ✓ **健保 9.107** | ❌ **未給付、自費** |
| 美國 FDA（輔助）| 已核准 | 2024/9 已核准 |

##### abemaciclib 健保給付要點（9.107）

> ribociclib 輔助**主要服務「abemaciclib 不符資格」的 N0 高風險病人**。

??? info "📋 展開 ribociclib 輔助細節：N0 高風險收案條件、用法、為什麼是 400 mg"

    **N0 高風險適用族群**（NATALEE 收案 / NCCN 2026 v2 Category 1）：

    | 淋巴結 | 腫瘤 | 條件 |

    | **N1–3 陽性** | 任意 | 符合者皆可 |

    > ⚠️ **搭配用藥**：輔助 ribociclib 應**依核准方案搭配 nonsteroidal aromatase inhibitor（NSAI，如 letrozole／anastrozole）**，**不建議與 tamoxifen 合併**，並需注意 **QT 延長**風險。

#### 三藥副作用衛教與通報分流

##### abemaciclib（捷癌寧）— 腹瀉是重中之重

- **腹瀉**：發生率 **80–90%**，**多在治療早期、隨時間改善**，多為輕中度
  - **病人衛教**：一出現軟便就**立即服用止瀉藥**（如 loperamide）+ 多補充水分電解質
  - **警示通報**：水瀉持續 24 小時、或合併發燒/出血 → **立即通報**
  - 必要時減量（150 → 100 → 50 mg）——**試驗的探索性分析顯示，因副作用進行適當減量後仍可維持治療效益**（不是「減量一定沒差」，是「不要為了忍副作用而硬撐或自行停藥」）
- **血液毒性**：嗜中性球低下 41–46%，但發燒性嗜中性球低下 < 1%（比 palbo/ribo 輕）
- **肝功能異常**：ALT/AST 升高 1–6%
- **靜脈血栓栓塞（VTE）**：約 5%，留意下肢腫痛、突發胸悶喘
- **間質性肺病（ILD）/肺炎**：約 2.1%，留意新發或惡化的咳嗽、喘、發燒
- **監測**：起始後**前 2 個月每 2 週**驗 CBC 與肝功能，之後依臨床調整

##### palbociclib（愛乳適）— 以血液毒性為主

- **嗜中性球低下**為最主要副作用，但機轉是「細胞週期暫停」（可逆）、與化療不同，**回復快、嚴重感染與發燒性嗜中性球低下少見**
- 其他：疲倦、噁心、口腔黏膜炎、脫髮（多輕微）
- **監測**：定期 CBC（依仿單於每週期起始與期中），依結果調整劑量

##### ribociclib（擊癌利）— 多了「心電圖」與「肝功能」兩道關卡

- **嗜中性球低下 + 疲倦**：與 palbociclib 類似
- **QTc 延長（特有）**：須**用藥前、約第 14 天（2 週）、及臨床需要時**追蹤心電圖；併用藥物須做交互作用審查（避免併用其他延長 QT 的藥物）
- **肝功能異常**：發生率較高，須定期監測肝功能
- **ILD/呼吸道毒性**：少見但需留意
- 噁心嘔吐多在第一個月後緩解

??? info "📋 展開 ribociclib 輔助（400 mg）副作用發生率與監測排程"

    > ⚠️ 以下百分比出自 **NATALEE 試驗**（ribociclib 400 mg 輔助，n ≈ 2,549），**表中已標明「任何等級」與「≥ G3」**。
    > **試驗族群 ≠ 本院病人**——實際發生率會因年齡、共病、合併用藥而不同。

    **ribociclib 輔助（400 mg）副作用發生率**（NATALEE，n ≈ 2,549）：

    | 副作用 | 任何等級 | ≥ G3 | 備註 |
    |---|---|---|---|
    | 嗜中性球低下 | 62.8% | 44.4% | 多為無症狀數值；**發熱性嗜中性球低下僅 0.3%**、中位緩解 0.3 月 |
    | 肝功能上升（ALT/AST）| 26.7% | 8.6% | 多低級別、可逆；中位緩解 0.7 月 |
    | QT 延長 | 5.4% | 1.0% | 避免併用延長 QT 藥物、維持電解質 |
    | 關節痛 | 38.8% | 1.0% | 多與內分泌治療相關 |

    > 💡 **共通特性**：**NATALEE 中多數副作用出現在治療早期（約前 6–8 個月）**，多為暫時、可透過暫停／減量恢復。**試驗的探索性分析顯示適當減量後仍可維持治療效益**——所以**遇到副作用先回報、由醫師調整，不要自行停藥**。

| 1 | **臨床治療分群**（ER/PR/HER2；Ki-67、Grade）| 決定整個治療主軸 | ☐ |
| 2 | **停經狀態** | 決定內分泌治療用哪一類（AI 需停經後）、要不要加卵巢功能抑制 | ☐ |
| 3 | 🔴 **是否有生育需求** | **化療可能影響生育力——要保留生育力必須在治療開始前轉介**，開始了就來不及 | ☐ |
| 4 | 🔴 **家族史與遺傳諮詢需求** | 影響**一整個家族**；也可能影響治療選擇（見 [FAQ](#q-哪些病人應該考慮遺傳諮詢與-brca-等胚系檢測上表-①)）| ☐ |
| 5 | 🔴 **基準心臟功能** | 預計用 **anthracycline／抗 HER2 治療**者，**治療前要有基準值**才能比較 | ☐ |
| 6 | 🔴 **基準骨質狀態** | 預計用 **AI／卵巢功能抑制**者——這兩類會加速骨質流失 | ☐ |
| 7 | 🔴 **術前治療者：腫瘤與陽性淋巴結位置是否已標記** | **術前治療會讓腫瘤縮小甚至看不見**，沒標記手術就找不到位置 | ☐ |
| 8 | **是否可能需要術後放療；乳房重建前是否完成跨科討論** | 重建方式與時機**會受放療影響**，術前就要談過 | ☐ |
| 9 | **病人的主要困擾**：乳房外觀、性健康、工作、家庭照顧 | 這些是乳癌病人真正在意的事，但他們常常不會主動說 | ☐ |
| 10 | 家庭支持系統、經濟狀況 | | ☐ |

!!! tip "第 9 項怎麼問"
    不要問「你有什麼困擾嗎？」（八成回答「還好」）。

    **問具體的**：「治療期間你還要上班嗎？」「家裡誰需要你照顧？」「對於手術後外觀的改變，你有想過嗎？」——**具體的問題才問得出真話**。

**特別注意：**

- **乳癌對身體意象、性健康、家庭角色的衝擊很大**，而且病人多半不會主動提
- **初診斷時情緒支持很重要**——但不要急著給資訊，先讓他把話講完

### 治療期間

**手術病人：**
- 術前：解釋手術方式、可能的外觀改變
- 術後：傷口照護、引流管照護
- 復健：肩關節活動、預防淋巴水腫

**化療病人：**
- 掉髮：事先衛教、協助假髮資源
- 噁心、疲倦：衛教處理方式

**荷爾蒙治療病人：**
- 長期服藥（5-10 年）
- 注意副作用：熱潮紅、關節痛、子宮內膜問題
- 追蹤服藥遵從性

**標靶治療病人（HER2+）：**
- 注意心臟毒性
- 定期追蹤心臟功能

### 特殊議題

#### 淋巴水腫

!!! danger "🔴 舊的「患側全面禁忌」衛教已經過時，不要再這樣教"
    以前教「**患側終身避免重物／針扎／量血壓**」——**現有證據不支持所有病人終身完全禁用患側手臂**。

    全面禁止患側量血壓、抽血或靜脈注射會造成**不必要的不便**（想像一個右側乳癌病人，右手終身不能抽血），而且**沒有證據顯示這樣做能預防淋巴水腫**。

**現在該怎麼教**：

| 主題 | 現在的說法 |
|------|----------|
| **運動** | **鼓勵循序漸進的肩關節與阻力運動**——**不需要終身避免使用患側手臂**。規律運動反而有幫助 |
| **抽血／打針／量血壓** | **有適當替代部位時優先用對側**；**若臨床需要使用患側，並非絕對禁止** |
| **例外——這時要避免** | **患側已有淋巴水腫、感染或傷口**時，避免侵入性處置並諮詢醫療團隊 |
| **體重** | **體重控制**對降低淋巴水腫風險有幫助 |
| **皮膚照護** | 保持完整、避免曬傷與割傷、有傷口早處理 |
| 🚩 **早期辨識** | **手臂／乳房／胸壁出現腫脹、緊繃、沉重感 → 儘早轉介復健或淋巴水腫專業人員**。早期處理效果好很多 |

> 💡 **風險高低看腋下手術範圍**——做了 **ALND** 的比只做 **SLNB** 的風險高很多（這也是為什麼[能省略 ALND 就省略](#腋下手術)很重要）。加放療會再增加風險。
>
> ⚠️ **病人被以前的衛教嚇到了怎麼辦**：很多病人已經被教成「這隻手廢了」。**要主動幫他鬆綁**——「你可以正常用這隻手，我們要注意的是這幾件事」比「你不能做這個那個」有用得多。

#### 生育議題

!!! warning "⏱ 這件事有時間窗——治療開始就來不及了"
    **化療可能影響生育力。要保留生育力，必須在治療開始前轉介。**

- **收案時就要問**（見 [收案 Checklist 第 3 項](#-收案評估-checklist)）——**不要等病人主動提**
- 年輕病人、或有生育規劃者 → **治療前轉介生殖醫學科**討論生育保存
- **內分泌治療會綁 5–10 年**——這對想生育的病人是很現實的問題，要讓他跟醫師談
- ⚠️ **不要替病人判斷「他應該不會想生」**——年齡不是唯一考量

#### 乳房重建

- 有需求 → **轉介整形外科**，說明時機（立即／延遲）與選項（自體／植入物）
- 🔗 **重建與放療必須一起討論**——**放療會影響重建的方式與時機**，術前就要跨科談過，不能等放療要開始才發現衝突（見 [放射治療](#放射治療)）
- **不要在病人剛確診、情緒最亂的時候逼他決定重建**——但**也不要都不提**，有些選項過了時機就沒了

#### 骨質健康

- **AI（芳香環酶抑制劑）與卵巢功能抑制會加速骨質流失**
- **治療前要有基準骨質狀態**（見 [收案 Checklist 第 6 項](#-收案評估-checklist)）
- 治療期間**定期追蹤骨密度**，必要時補鈣／維生素 D／抗骨鬆藥物
- 💡 **病人常以為「骨頭痛 = 骨轉移」**——其實 AI 的關節／骨頭酸痛很常見。**不要自己判斷是哪一種，回報醫師**

#### 心臟健康（抗 HER2 / anthracycline）

- **anthracycline 與抗 HER2 治療都有心臟毒性**
- **治療前要有基準心臟功能**（見 [收案 Checklist 第 5 項](#-收案評估-checklist)）——**沒有基準值，之後掉了也比不出來**
- 治療期間**定期追蹤心臟功能**
- 🚩 **喘、下肢水腫、活動耐受度下降 → 回報醫師**（不要當成「化療都會累」）

## 六、常見問題與處理

### Q: 病人問「我可以保留乳房嗎？」

A: **要由醫師評估**——但你可以幫他理解影響因素，也可以先安撫他最常見的恐懼。

**⚠️ 不要說「保留與否不影響存活率」——這句話少了前提，對某些病人是錯的。**

**正確的說法**：

> 「**對於適合接受乳房保留治療的早期乳癌病人**，完整接受**乳房保留手術 + 放射治療**，存活結果通常與全乳切除相當。但適不適合要看腫瘤範圍、切緣、乳房與腫瘤的比例、能不能接受放療，還有你自己的意願——這要請醫師評估。」

**為什麼要加前提**：

| 情況 | 「不影響存活率」這句話會出什麼問題 |
|------|------------------------------|
| **局部晚期、廣泛多發病灶** | 他根本不適合保乳，聽了會以為「那我堅持保乳也沒差」 |
| **不能接受放療的病人** | **保乳的前提是要能做放療**——不能放療就不是「保乳 vs 全切」的選擇題 |
| **切緣一直達不到的病人** | 可能要再次手術甚至改全切，事先沒講會覺得被騙 |

**個管師實務**：

- **先聽他為什麼想保乳**——怕外觀改變？怕先生的反應？怕別人看出來？**恐懼具體了才好處理**
- **提醒他重建也是選項**（見 [乳房重建](#乳房重建)），而且**重建要跟放療一起討論**
- **把他真正在意的事帶回去給醫師**，讓醫師在有脈絡的情況下談

### Q: 病人很擔心掉髮

A:
- 同理她的擔心（這很正常）
- 說明大約何時會掉、何時會長回來
- 介紹假髮資源（癌症資源中心可借用）
- 有些化療方案掉髮較少，可跟醫師討論

### Q: 病人荷爾蒙治療吃了很不舒服想停藥

A:
- 了解是什麼副作用
- 說明荷爾蒙治療的重要性（降低復發）
- 很多副作用可以處理或換藥
- 安排回診與醫師討論，不要自行停藥

### Q: 病人問可不可以懷孕

A:
- 這是複雜的問題，需要醫師評估
- 一般建議治療完成後一段時間再考慮
- 若有生育計畫，治療前要提出
- 可轉介生殖醫學科諮詢

### Q: 為什麼 CDK4/6 抑制劑要 HER2 陰性才能用？

A:
- 因為 CDK4/6 抑制劑針對的是「HR 陽性」乳癌的細胞增殖路徑，**HER2 陰性**是健保納入給付的試驗族群（試驗都建立在 HR+/HER2- 病人）
- **HER2 陽性**有專屬且效果很好的標靶藥（如 Trastuzumab、T-DXd 等），走的是完全不同的治療路徑

### Q: abemaciclib 為什麼健保要求「放療後」才能用？

A:
- **三個理由**：(1) 對齊試驗時序（試驗是手術 → 化療 → 放療 → 才開始 abemaciclib）(2) 避免毒性疊加（CDK4/6 抑制劑跟放療有重疊毒性：骨髓抑制、皮膚、肺）(3) 確保治癒性局部治療完成（先完成 RT、避免因標靶治療而延後放療）
- 個管師務必追蹤 **RT 完成日**，這是事前審查最常卡關的點

### Q: 淋巴結陰性（LN-）病人可不可以用 CDK4/6 抑制劑？

A:
- **abemaciclib 不行**——健保給付要求**淋巴結陽性**。abemaciclib 是「**沒被研究**」，**不是「研究失敗」**——試驗（monarchE）從收案就要求至少一顆陽性淋巴結
- **ribociclib 有實證但需自費**——NATALEE 試驗有收 **高風險 N0**（見下方資格）。**台灣健保未給付輔助 ribociclib**，需自費
- **N0 高風險（可考慮 ribociclib 自費輔助）**：
  - **T2 / N0 / Grade 3** — 直接符合
  - **T2 / N0 / Grade 2** + （Ki-67 ≥ 20% **或** 基因檢測高風險）
  - **T3–4 / N0**（> 5 cm 或侵犯胸壁皮膚）— 直接符合
  - **T1 / N0**（≤ 2 cm）— **不符合**
- **個管師動作**：(a) LN- 病人不要誤送 abemaciclib 9.107 申請（會被退）(b) 若病人 N0 但屬高風險、可由醫師評估自費 ribociclib (c) 自費溝通要先做財務評估與諮詢

### Q: 微轉移（N1mi）算不算淋巴結陽性？

A: **要分成兩個問題回答，不要混在一起。**

| 問題 | 答案 |
|------|------|
| **分期上算不算？** | **算。** N1mi 屬 **pN1**（淋巴結陽性），跟真正的 pN0（陰性）是兩回事 |
| **健保 9.107 事審會不會採認？** | ⚠️ **不確定，要問。** 條文寫的是「淋巴結陽性」與「pALN 1–3 顆」，**並未明文寫出 N1mi** |

- **送審前向院內事審窗口／健保窗口確認**，不要自己認定、也不要向病人保證會過
- **不要因為「分期上算」就直接送**——分期規則和給付認定是兩套系統
- 條文全文見 [drug-lookup 抗癌藥物速查](../drug-lookup/){target=_blank}

### Q: 病人說「醫師叫我做基因檢測」，是哪一種？

A: 🔴 **「基因檢測」在乳癌是三件完全不同的事，先問清楚是哪一種——講錯會嚇到病人。**

| 類型 | 驗什麼 | 目的 | 誰會做 |
|------|--------|------|--------|
| **① 遺傳性胚系檢測**<br>（germline）| **抽血**驗你天生的基因 | 評估**遺傳風險**、家屬要不要驗、部分治療選擇 | BRCA1/2、PALB2 等——**有家族史／年輕／TNBC 等**（見下題）|
| **② 腫瘤基因表現風險檢測**<br>（tumor gene expression）| 驗**腫瘤組織**的基因表現 | 判斷**復發風險與化療獲益** | Oncotype DX、MammaPrint、Prosigna、EndoPredict |
| **③ 腫瘤體細胞分子檢測**<br>（somatic）| 驗**腫瘤**的突變 | 選**標靶治療** | 多用於**晚期**疾病 |

!!! danger "🔴 為什麼一定要問清楚是哪一種"
    - **① 會影響「家人」**——病人聽到「基因」常直接想到「會不會遺傳給女兒」。如果醫師開的其實是 ②，你講成遺傳，病人會白擔心一場
    - **② 不看遺傳**——它是看腫瘤的行為，**跟家族史無關**
    - **三種的檢體、費用、報告時間、對象都不一樣**

    **個管師的第一句話應該是**：「醫師是幫你抽血驗，還是拿之前的腫瘤組織去驗？」——**檢體來源就分得出來**。

### Q: 什麼情況會做「乳癌多基因表現風險檢測」？（上表 ②）

A:
- **目的**：協助分層**復發風險**、判斷**化療獲益**、或決定是否做輔助 CDK4/6 抑制劑（限 ribociclib）
- **常見時機**（只有特定族群會碰到）：
  - **HR+/HER2−、早期、化療獲益不確定**——醫師可能用它決定要不要加化療
  - **T2 / N0 / Grade 2** 病人——想申請輔助 ribociclib（自費）時、若 Ki-67 < 20% 才會用它確認高風險
- **常見檢測**：Oncotype DX（RS ≥ 26 為高風險）、MammaPrint、Prosigna (PAM50)、EndoPredict
- **台灣現況**：多為**自費**（單次數萬元）、可近性與成本需納入考量
- **個管師動作**：(a) 確認醫師是否有開單 (b) 病人自費前先衛教用途與費用 (c) 報告出來後追蹤是否影響治療決策
- ⚠️ **它不看遺傳**——病人問「那我女兒會不會也有」，那是上表 ① 的事

### Q: 哪些病人應該考慮遺傳諮詢與 BRCA 等胚系檢測？（上表 ①）

A: **這題個管師常常漏掉，但它影響的是「一整個家族」。**

**常見的考慮時機**（實際條件依院內與國健署／健保規定，**以醫師與遺傳諮詢門診為準**）：

| 情境 | 為什麼 |
|------|--------|
| **年輕發病** | 越年輕越可能有胚系致病變異 |
| **三陰性乳癌** | TNBC 與 BRCA1 相關性較高 |
| **雙側乳癌／多發原發癌** | |
| **家族有乳癌／卵巢癌／胰臟癌／攝護腺癌** | 尤其多人、年輕、或男性乳癌 |
| **男性乳癌** | |
| **可能影響治療選擇時** | 部分治療與 BRCA 狀態相關 |

**個管師動作**：

1. **收案時就問家族史**（見 [五、收案時](#收案時)）——不要等到治療都開始了才想到
2. **有疑慮 → 提醒醫師、協助轉介遺傳諮詢門診**
3. ⚠️ **不自行判斷病人「需不需要驗」**、更**不要直接跟病人說「你這個會遺傳」**——胚系檢測牽涉家屬、保險、生育決策，**一定要走正式的遺傳諮詢**
4. **檢測前後都要有諮詢**——這不是抽個血就好的事

> 📅 **時效提醒（規則 15）**：胚系檢測的**適應條件與給付**會變動，**以醫師、遺傳諮詢門診與最新公告為準**。

### Q: 病人 N0 高風險、想用自費 ribociclib 輔助，要怎麼溝通？

A:
- **先講清楚 3 件事**：
  1. **健保不給付** — 輔助 ribociclib 美國 FDA 2024/9 核准、但**台灣健保未給付**、需自費
  2. **療程長** — **3 年** 400 mg/日 + 搭配 AI ≥ 5 年（療程比 abemaciclib 2 年長 1 年）
  3. **副作用主要在前 6–8 個月** — 嗜中性球低下、肝功能上升、QT 延長；多數可逆、暫停/減量可恢復
- **財務評估**：協助病人試算自費總額、是否申請商業保險、或評估能否參與廠商支援方案
- **轉介社工**：經濟有困難時轉介評估補助資源
- **若病人決定不用**：尊重決定、改密集追蹤（內分泌治療 ≥ 5 年 + 定期影像）

### Q: 輔助 abemaciclib 沒效，轉移後可以接 palbociclib 或 ribociclib 嗎？

A:
- **不行**——這是個管師高度警示的「**跨線排他規則**」
- 健保 9.72 明訂：**先前於早期乳癌使用 abemaciclib 無效後，不得再申請 ribociclib／palbociclib**
- 追蹤輔助 abemaciclib 病人時要意識到這個跨線影響，疾病進展時提早跟醫師討論其他方向
