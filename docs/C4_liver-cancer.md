# C4. 肝細胞癌（HCC）照護指引

**彰濱秀傳癌症中心｜個管師指導書系列**

!!! danger "🔴 本文件所稱「肝癌」限指肝細胞癌（hepatocellular carcinoma, HCC）"
    **長在肝臟的惡性腫瘤不只一種，治療路徑完全不同。** 不要混在一起：

    | 疾病 | 是什麼 | 看哪一檔 |
    |------|--------|---------|
    | **肝細胞癌（HCC）** | 肝細胞長出來的原發性肝癌——**本檔** | ✅ **C4（本檔）** |
    | **肝內膽管癌（iCCA）** | 肝內膽管上皮長出來的——**屬膽道癌，走完全不同的路** | [C9 肝膽胰癌](C9_biliary-pancreatic-cancer.md) |
    | **混合型 HCC-CCA** | 罕見、兩者混合 | ⚠️ 依 MDT 個別決定，本手冊未涵蓋 |
    | **肝轉移** | **別的癌跑到肝臟**（大腸癌肝轉移最常見）——**不是肝癌** | 回原發癌別檔（如 [C3 大腸直腸癌](C3_colorectal-cancer.md)）|

    💡 **個管師收案第一件事：確認病理／影像診斷寫的是 HCC，不是 iCCA 也不是肝轉移**（見 [收案 Checklist](#收案-checklist)）。

## 一、疾病概述

### 流行病學

- 台灣癌症死亡率：長年位居前 2 位
- 主要病因：**B 型肝炎（約 70%）**、C 型肝炎（約 20%）、酒精性肝病、脂肪肝
- 平均診斷年齡：60–70 歲
- 男女比：約 3:1（男性高）
- 本院每年新案數：約（待補充）例

### 危險因子

| 危險因子 | 說明 |
|---------|------|
| **B / C 型肝炎** | 最主要——每位肝癌病人都要查 HBV / HCV 狀態 |
| **肝硬化** | 任何原因（病毒、酒精、NAFLD）導致的肝硬化 |
| **黃麴毒素** | 發霉花生、玉米 |
| **酒精性肝病** | 長期飲酒 |
| **脂肪肝（NAFLD/NASH）** | 近年比例上升 |
| **家族史** | 一等親肝癌史 |

### 常見症狀

- **早期常無症狀**（這是肝癌可怕之處——靠定期篩檢才能早期發現）
- 右上腹脹痛
- 食慾不振、體重減輕、疲倦
- 黃疸、腹水（晚期 / 肝功能差時）
- 食道靜脈瘤出血（門脈高壓）

!!! warning "⚠️ 高風險監測是「每 6 個月」，不是「3–6 個月」"
    **B 型肝炎、C 型肝炎、肝硬化及其他符合風險條件者，原則上每 6 個月接受腹部超音波 + AFP 監測。**

    **「3 個月」是特殊情況，不是常規**——通常是**已發現未定性結節後的短期追蹤**，或其他特殊臨床情境；追蹤間隔依醫師及影像分類決定。

    💡 **用詞也要注意**：這叫 **HCC surveillance（高風險監測）**，不叫「篩檢」——**這些人已經是已知的高風險族群**，跟一般人口的癌症篩檢（如[五癌篩檢](D2_education.md#五癌篩檢推廣年度推廣文宣)）不是同一件事。跟病人講「你要定期監測」比「你要去篩檢」精確。

## 二、診斷與分期

### 診斷流程

```
    高風險監測（每 6 個月 AFP + 超音波）／ 症狀懷疑
                    ↓
            發現肝結節
                    ↓
        多期動態 CT ／ 多期對比增強 MRI
                    ↓
        符合正式影像診斷標準？
        ├─ 是 → 可臨床診斷 HCC（不一定需切片）
        └─ 否 → 換另一影像工具 ／ 短期追蹤 ／ 切片
                    ↓
        肝功能與肝臟儲備評估（Child-Pugh、ALBI、門脈高壓、失代償）
                    ↓
            BCLC 分期 + ECOG
                    ↓
            MDT 討論治療計畫
```

!!! danger "🔴 「影像看起來像」不等於可以直接當 HCC——有前提"
    肝癌確實可以**不切片、靠影像直接臨床診斷**，這是它跟其他癌別最大的不同。**但這個做法有適用前提**：

    > **非侵入性影像診斷主要適用於肝硬化或慢性 B 型肝炎等 HCC 高風險族群。**

    **不是任何人只要影像上看到「動脈期增強 + washout」就能直接當 HCC。**

    實際判讀還涉及：**病人是否屬適用族群**、腫瘤大小、non-rim arterial phase hyperenhancement、washout appearance、enhancing capsule、threshold growth、**用的是細胞外還是肝細胞特異性顯影劑**。

    ⚠️ **個管師不必背完整 LI-RADS，但要知道**：**「影像看起來像」不等於個管師可以自行確認是 HCC**。診斷由影像科與主治醫師判定（見 [C0 → 個管師不做的事](C0_general.md#個管師不做的事)）。

### 必要檢查項目

| 檢查 | 目的 | 備註 |
|------|------|------|
| **多期動態 CT** 或 **多期對比增強 MRI** | 確診、分期 | **由醫師依腎功能、肝功能、病灶大小、既有影像品質及臨床問題選擇**。MRI 可用**細胞外**或**肝細胞特異性**顯影劑——**並非每位病人都固定用同一種**。🔴 **BCLC 2026：應由「肝癌專責放射科醫師」判讀**，因為**多一顆結節或直徑量得不準，期別就會跑掉**。必要時加**胸部 CT** 完成分期 |
| **對比劑超音波（CEUS）** | CT/MRI **不明確時**的輔助工具 | 原文列為 acceptable **complementary** tool |
| ❌ **PET** | — | 🔴 **BCLC 2026 明確「不建議」**用於 HCC 分期。病人問「要不要自費做 PET」→ **請他問醫師，不要說「做了比較保險」** |
| **AFP** | 腫瘤指數、追蹤反應 | 約 60-70% 病人 AFP 上升（**代表 30-40% 不會升，AFP 正常不能排除**）|
| 🔴 **HBV / HCV**（分開查、分開處理）| 病因評估、抗病毒治療指徵 | **必查**——**兩者處理邏輯完全不同**，見 [四、特殊注意事項](#四本癌別特殊注意事項) |
| **肝功能與肝臟儲備** | Child-Pugh / ALBI；必要時 MELD、門脈高壓、失代償評估 | 影響**每一個**治療決策 |
| **上消化道內視鏡** | 見下方兩種用途 | |

!!! warning "⚠️ 胃鏡不是「肝硬化就一定要做」——要看是為了什麼"
    | 用途 | 適用情境 |
    |------|---------|
    | **肝硬化／門脈高壓照護** | 是否需要胃鏡，**依門脈高壓風險及肝病指引評估**——不是所有肝硬化都一律做 |
    | 🔴 **預計使用 bevacizumab 前** | **需特別確認近期是否已評估食道胃靜脈瘤及出血風險**（IMbrave150 採**治療前 6 個月內**胃鏡評估）|

    💡 **個管師實務**：病人要開始 atezolizumab + bevacizumab 時，**主動確認「最近半年內有沒有做過胃鏡」**——沒做的話治療會卡住。

### BCLC 分期（巴塞隆納臨床肝癌分期）

> 📋 **版本說明**：肝細胞癌**臨床主用 BCLC**（整合腫瘤、肝功能、體能狀態決定治療）；癌登另有 AJCC TNM 欄位，**肝臟尚未釋出 AJCC Version 9、第 8 版就是現行版**。全站版本對照的權威源見 [C0 → 分期系統版本對照表](C0_general.md#分期系統版本對照ajcc-已改逐部位滾動更新)。

> 肝癌**主要使用 BCLC 分期**而非 TNM——因為 BCLC 同時考慮腫瘤、肝功能、體能狀態，更能反映治療決策。

!!! danger "🔴 BCLC 不是「期別對應唯一治療」的死表格"
    **BCLC 2026 保留了 0/A/B/C/D 的框架，但強調的是**：腫瘤負荷的**異質性**、**治療目標**、**MDT 與病人個別因素**，以及 **treatment-stage migration**（病人會因共病、年齡、可行性、治療反應或自己的決定而在期別間移動）。

    **下表是「這一期的第一線選項大概是什麼」，不是「這一期只能做這個」。**

| BCLC 期 | 條件（BCLC 2026 原文定義）| **第一線**選項 | **預期中位存活** |
|---------|---------|------|:---:|
| **0 期 極早期** | **單一 ≤ 2 cm**、無大血管侵犯、無肝外轉移、**肝功能保留**、**無癌症相關症狀** | **消融**（MW/RFA）| **> 5 年** |
| **A 期 早期** | **單一 > 2 cm**，或 **≤ 3 顆且每顆 ≤ 3 cm**；無大血管侵犯、無肝外轉移、肝功能保留、ECOG 0 | 單顆→**切除**；≤3 顆→**消融**或**移植** | **> 5 年** |
| **B 期 中期** | 🆕 **多發（multifocal）＝「> 3 顆」或「≤ 3 顆但至少一顆 > 3 cm」**、肝功能保留、ECOG 0 | **TACE** | **> 2.5 年** |
| **C 期 晚期** | **大血管侵犯 和／或 肝外轉移**（**不論肝內腫瘤負荷**）、肝功能保留、**ECOG 0–2** | **全身性治療** | **約 2 年** |
| **D 期 終末期** | 任何腫瘤負荷 + **末期肝功能** 或 **ECOG 3–4** | **BSC**（支持照護）| **< 1 年** |

!!! info "📊 「預期中位存活」這一欄：BCLC 2026 原文的數字，怎麼用"
    **這一欄是 BCLC 2026 原文給的**（J Hepatol 2026;84(3):631-654），不是本手冊自己估的——**個管師需要量級感，這是有出處的量級感**。

    **原文自己下的但書（一定要一起看）**：

    | | |
    |---|---|
    | ⚠️ **這是「最好情況」** | 原文：這些數字代表**接受有效第一線治療下的 best-case outcomes**，「individual prognosis varies widely」|
    | 🔼 **實際可能更長** | 原文：若**及時接續下一線 stage-appropriate 治療**，存活可**遠超過這些中位數**。但**「能接續治療」本身就是預後好的指標**，不代表某個接續策略有效 |
    | 🔽 **D 期內部差很大** | 原文：**嚴格符合 BCLC-D 定義者中位存活 < 3 個月**；但 BSC 這群人很異質（有些是早期但因共病或病人選擇而保守處理），所以 **2026 版把圖上的 D 期預期存活從 < 3 個月改成 < 12 個月** |

    ✅ **能怎麼用**：建立量級感、理解醫師的態度、**判斷是不是該提早接緩和／安寧資源**
    ❌ **不能怎麼用**：**不能拿來跟病人說**。病人問「我還能活多久」→ 見 [FAQ](#q-病人問我還能活多久)

!!! danger "🔴 BCLC 2026 對 B 期的具體改變：把「多發（multifocal）」定義清楚了"
    **這是 2026 版對分期定義唯一的實質修改**（其餘 0/A/C/D 沿用 2022）：

    > **Multifocal ＝「> 3 顆」，或「≤ 3 顆但其中至少一顆 > 3 cm」**

    💡 **對個管師的意義**：以前「多發性腫瘤」講不清楚，**現在有明確的數字**。看到「2 顆，一顆 4 cm 一顆 2 cm」——**那是 B 期不是 A 期**（因為有一顆 > 3 cm）。

!!! danger "🔴 第一個分岔點不是腫瘤，是「肝硬化代償了沒」"
    **BCLC 2026 的流程圖（Fig. 2）第一步問的不是腫瘤多大，是「有沒有肝硬化？代償還是失代償？」**

    | 狀況 | 預後由什麼決定 |
    |------|-------------|
    | **代償性肝硬化** | 主要由 **HCC 的生物學與範圍**決定 → 走 BCLC 0/A–D |
    | **失代償性肝硬化** | **殘餘肝功能 + HCC 範圍與生物學**一起決定 |
    | **沒有肝硬化**、或 **HCV 治癒後**發生的 HCC | 預後**幾乎完全由 HCC 生物學**決定 |

    🔑 **失代償不是絕對且不可逆的禁忌**——原文明講：**治療病因（如 HBV 抗病毒、酒精性肝病戒酒）或妥善控制併發症後，若達到「再代償（recompensation）」，可以重新進入特定治療路徑**。

    ⚠️ **但不要給病人過高期待**：原文也說，**實際只有約 7% 的人符合 Baveno VII 的再代償標準**；即使用放寬的標準也只到 37%，而且那些人**沒有一個有 HCC**。**大多數 BCLC-D 病人不會達到再代償。**

    💡 **這正是為什麼 [HBV/HCV 要分開處理](#-hbv-與-hcv不要寫成bc-肝抗病毒治療)很重要**——原文：HBV 抗病毒可讓相當比例病人再代償；酒精性肝硬化持續戒酒約 **15–20%** 達再代償；HCV 各世代研究報告 **36–64%**。

!!! warning "⚠️ A 期不能只用 Child-Pugh A–B 一刀切"
    現行 BCLC 越來越強調「**preserved liver function（肝功能保留）**」而不是單純用 Child-Pugh A/B 分。

    **肝功能與肝臟儲備要完整評估**——Child-Pugh 是**共通工具之一**，另依情況評估：**ALBI**、**MELD**、**是否有臨床顯著門脈高壓**、**腹水與肝性腦病**、**預估殘餘肝功能**。

    ⚠️ 所以本手冊不寫「Child-Pugh 必做，影響每個治療決策」——而是「**肝功能與肝臟儲備必須完整評估，Child-Pugh 是其中一項工具**」。

!!! danger "🔴 BCLC D ≠ 一律只有安寧"
    D 期**通常**代表末期肝功能或嚴重體能受限，以**支持與緩和照護**為主。**但有重要例外**：

    > **肝功能衰竭的病人，若腫瘤負荷符合條件且可接受肝移植，應由移植團隊另外評估**——不能因為 Child-Pugh C 就直接歸為只有 BSC。

    **而且 ECOG 不好要先問「為什麼不好」**：

    | 原因 | 意義 |
    |------|------|
    | **腫瘤造成** | 可能治療後改善 |
    | **肝衰竭造成** | 可能 recompensation 後改善、或評估移植 |
    | **其他共病造成** | 跟肝癌本身無關 |

    ⚠️ **不能只看一個分數就下結論。**

## 三、治療指引

> ⚠️ **依據準則**：**BCLC 2026 update**、台灣肝癌醫學會／台灣消化系醫學會 HCC 共識、**台灣肝癌醫學會中期肝癌管理共識（2025）**、EASL、ASTRO 原發性肝癌放療指引。**待醫師團隊確認版本與本院實作差異**。

!!! danger "🔴 UTP（untreatable progression）：影像沒進展，也可能要換下一期的治療"
    **這是 BCLC 2026 一個個管師非知道不可的概念。**

    > **原文**：UTP「first defined for TACE **but now applied across all stages**」——它代表**目前這個策略失敗了**，要**轉到下一個 BCLC 期別建議的治療**，**「even in the absence of radiological progression」**。

    **白話**：不是「腫瘤變大才叫失敗」。**做不下去了（肝功能撐不住、技術上沒辦法再做、副作用太大）就是失敗**，該換路了。

    | 病人的話 | 為什麼會這樣 |
    |---|---|
    | 「我的腫瘤又沒變大，為什麼要換藥／換方式？」 | **UTP**——現在這個做法已經走不下去了，不是等腫瘤變大才換 |
    | 「醫師說不能再做栓塞了，是不是沒救了？」 | **不是**——是要換到下一階的治療（通常是全身治療），**這是計畫內的轉彎** |

    💡 **相關概念：treatment-stage migration（TSM）**——病人會因為**共病／年齡／體弱、可行性、UTP、治療反應太好、或病人自己的決定**而在期別之間移動。**BCLC 不是單行道。**

    🔑 **還有一個新概念**：免疫治療時代出現「**治療後大幅反應（major response）**」——原文說這**還沒有共識定義**，是目前 HCC 決策最大的不確定來源之一（腫瘤縮很多之後還要不要／能不能做後續治療，沒人知道）。

### 局部治療：不是只有手術、RFA、TACE

> 🔴 **這是本檔前一版最大的缺口**。BCLC 2026 已把 **SBRT 與 TARE 列入 0/A 期的 potentially curative 選項**，教材不能只寫手術/RFA/TACE。

| 治療 | 個管師應知道的角色（依 BCLC 2026）|
|------|------------------|
| **手術切除** | 單一腫瘤、**肝功能保留**、**無臨床顯著門脈高壓（CSPH）**。**可行時優先微創**（腹腔鏡／機器人）|
| **肝臟移植** | 符合條件者（Milan 是常用標準之一，**不是唯一**——見 [FAQ](#q-病人問我可以換肝嗎)）。🔴 **AFP > 1,000 ng/ml 是廣泛認定的移植禁忌**（不論腫瘤負荷）|
| **微波消融 MW** | 🆕 **原文：3–4 cm 以下腫瘤，MW 的局部控制比 RFA 更可靠，「可行時是首選的經皮技術」**——不要把 MW 當成 RFA 的次要替代 |
| **射頻消融 RFA** | 熱消融；與 MW 同為 0/A 期的支柱 |
| 🆕 **TARE ／ Y-90** | 肝動脈內放射治療——**BCLC-0 的有效替代**（LEGACY、RASER 試驗）；可用於**橋接**或**降期**。🔴 **原文：若要做 TARE，個人化劑量學（DOSISPHERE-01）應為標準做法** |
| 🆕 **外部放射治療 EBRT ／ SBRT** | 🔴 **原文：BCLC 2026 把 EBRT 納為 BCLC-0 的「ablative option」**。也用於血管侵犯（RTOG 1112）、橋接、症狀緩解 |
| 🆕 **質子／碳離子** | EBRT 的一種；特定中心與適當病人可考慮 |
| 🆕 **肝動脈灌注化療 HAIC** | **亞洲**（主要中國）試驗顯示優於 sorafenib，**但未在多區域族群證實**——原文列為「其他方案」|
| **TACE** | **B 期的第一線標準**——見下方 B 期段。⚠️ **原文明列 TACE 為「non-ablative」** |

!!! warning "⚠️ 我上一版寫錯了一句，這版更正"
    **上一版寫「BCLC 2026 新列 SBRT 與 TARE 為 0/A 的 potentially curative 選項」——那是二手來源的概括，原文更精確也更保守**：

    - **BCLC-0**：原文明講「**BCLC 2026 incorporates EBRT as an ablative option in BCLC-0 patients**」；TACE／TARE／EBRT「may achieve comparable outcomes，是現行實務的 valid alternatives」，**最終選擇取決於腫瘤特徵、專業能力與在地資源**
    - **BCLC-A 多發**：原文只說「圖上加了一個 **CUSE 註記**，表示 resection、TARE、EBRT **在選擇性個案**可考慮」——**不是常規選項**
    - 🔴 **BCLC-B**：**原文明確「不支持」TARE 或 SBRT 作為 TACE 的第一線替代**（見下方 B 期段）

    💡 **這就是為什麼要看原文**——二手摘要把三個不同層級的建議壓成一句「0/A 新增 SBRT/TARE」（坑 #68）。

> 💡 **個管師為什麼要認得這些名詞**：病人拿到治療計畫書寫「SBRT」或「Y-90」，**你要知道那不是「放棄治療」也不是「實驗性治療」**——它們是現行準則裡的正式選項。**認不出來就沒辦法安撫病人。**

### 0 / A 期（極早期 / 早期）

| 治療 | 適用情境 |
|------|---------|
| **手術切除** | 單一腫瘤、肝功能保留、無臨床顯著門脈高壓 |
| **消融（RFA / MWA）** | 腫瘤較小、位置適合、或不適合手術 |
| **肝臟移植** | 符合移植條件、合併嚴重肝硬化時的重要選項 |
| 🆕 **SBRT ／ TARE** | **BCLC 2026 新列為 potentially curative 選項** |

### B 期（中期）

!!! danger "🔴 BCLC B ≠ 一直重複 TACE 到失敗"
    **前一版寫「TACE 可重複進行；無效時升級到 C 期治療」——這個講法過時而且危險**，會造成「一直做到不能做」的錯誤印象。

    **BCLC 2026 把 B 期分成三個 subgroup**（原文）：

    | # | 族群 | 方向 |
    |:-:|------|------|
    | **1** | **腫瘤界線清楚**、符合該院 **Extended LT criteria**（大小、AFP）| **評估肝移植**。🔴 **AFP > 1,000 ng/ml 是禁忌** |
    | **2** | 不符移植、但**門脈血流保留**、腫瘤範圍明確、**可選擇性到達供血動脈** | **TACE（第一線標準）** |
    | **3** | **瀰漫性、浸潤性、或廣泛雙葉侵犯**——**無法做選擇性 TACE** | **全身治療**（原文：沒有嚴格的 cut-off 定義這個轉換點）|

    **正確的概念**：

    > **BCLC B 應先判斷是否適合「選擇性」TACE。** 若**腫瘤負荷過高**、**無法選擇性治療**、**肝功能可能因反覆 TACE 惡化**、或**已有 TACE 無反應**，應**儘早回到 MDT 評估其他局部或全身性治療**——**而不是固定重複 TACE**。

    📋 台灣肝癌醫學會 **2025 年**已發表專門處理 **BCLC B／中期 HCC** 的管理共識，重點就是依 **TACE suitability** 與個別腫瘤特徵分流。

    🚩 **個管師要留意的訊號**：病人做了好幾次 TACE、**肝功能一次比一次差**、或**影像顯示沒反應**——**這時要確認有沒有回 MDT 重新討論**，不要理所當然地排下一次。

!!! danger "🔴 B 期不能用 TARE／SBRT 取代 TACE——但「為什麼不能做 TACE」決定了下一步"
    **原文明講**：「The current BCLC strategy **still does not support TARE or SBRT as first-line alternatives to TACE** in this context」——因為這些療法在**非 TACE 候選者**的資料，主要來自 **BCLC-A** 病人。

    **關鍵是要問「為什麼不能做 TACE」**：

    | TACE 不可行的原因 | 下一步 |
    |---|---|
    | 🔴 **腫瘤負荷過大**（瀰漫、廣泛雙葉）| **直接走全身治療** |
    | **技術原因**（非腫瘤負荷）| **TARE 或 EBRT 可考慮**——目的是**延後全身治療、把它留給進展時用**，不是因為它們比較好 |

    💡 **個管師的價值**：病人問「為什麼我不能做栓塞？」——**這兩種原因的意義完全不同**，一種是病比較廣，一種是血管走向不好做。**不要混講，也不要自己判斷是哪一種。**

**TACE 實務**：阻斷腫瘤血流 + 注入化療藥；治療次數依反應而定，約每 2-3 個月評估。

!!! warning "⚠️ 「TACE + 免疫／標靶」目前不建議在臨床試驗外使用"
    病人可能會聽說「栓塞加免疫效果更好」。**BCLC 2026 原文的立場很明確**：

    > 多區域三期試驗（EMERALD-1、LEAP-012、TALENTACE）雖然改善了 PFS，**但 OS 資料仍不成熟**；LEAP-012 的期中結果甚至顯示**不太可能達到統計顯著的 OS 效益**。中國的三個大型 RCT 有效益但**未在其他族群驗證**。
    >
    > **「At present, TACE-based combinations cannot be recommended outside clinical trials.」**

    💡 **個管師的回應**：「這個組合目前還在研究階段，**要不要用、適不適合你，要由醫師和 MDT 評估**。」——**不要說「這個更好」也不要說「這個沒用」。**

### C 期（晚期 / 全身性治療）

!!! warning "⚠️ 不要背「首選 / 替代」的固定排名——選擇依臨床情境"
    | 臨床情境 | 治療方向 |
    |---------|---------|
    | **肝功能保留、可接受免疫與抗 VEGF** | 評估 **atezolizumab + bevacizumab** |
    | 🔴 **高出血風險、不宜 bevacizumab** | 評估**雙免疫治療**或 **TKI** |
    | 🔴 **自體免疫疾病／器官移植等免疫禁忌** | 評估 **TKI 等非免疫路徑** |
    | **肝功能較差或特殊門脈侵犯** | 由 **MDT 依實證與院內規範個別決定** |

    **目前國際上的第一線選項至少包括**：atezolizumab + bevacizumab、tremelimumab + durvalumab（STRIDE）、nivolumab + ipilimumab、lenvatinib、sorafenib。

!!! danger "🔴 國際核准 ≠ 台灣可用"
    **實際使用必須同時確認**：

    | 待確認 | 找誰 |
    |--------|------|
    | **TFDA 藥證**現行適應症 | 藥局 / 主治醫師 |
    | **台灣健保**給付條件與線別 | 院內事審窗口 / [drug-lookup 抗癌藥物速查](../drug-lookup/){target=_blank} |
    | **院內事審條件** | 事審窗口 |

    📅 **查證日期**：（待填——完成查證後填入）

    ⚠️ **個管師不要跟病人說「現在第一線都用某某藥」**——請他們問醫師。（同 [C2 ribociclib](C2_breast-cancer.md#ribociclib-輔助治療要點natalee--自費)、[C3 BRAF](C3_colorectal-cancer.md#braf-v600e治療組合已變動不要背固定配方) 的教訓）

#### 第二線：不是可互換的藥物清單

!!! warning "⚠️ 第二線的選擇受第一線用了什麼影響"
    | 藥 | 原文寫的限制 |
    |----|------------|
    | **Regorafenib** | **限「sorafenib-tolerant」**——證據來自**曾耐受 sorafenib 且進展**者（RESORCE）|
    | **Ramucirumab** | 🔴 **限 AFP > 400 ng/ml**（REACH-2）——**不論先前是否耐受 sorafenib**。**AFP 沒到就不適用** |
    | **Cabozantinib** | **不論先前是否耐受 sorafenib** 都可用（CELESTIAL）；**也可作為第三線** |

    !!! danger "🔴 原文最重要的一句：只有 sorafenib 之後有實證的接續路徑"
        **原文**：「Among first-line therapies, **only sorafenib supports an evidence-based sequencing strategy**, as validated pathways following other first-line regimens are lacking.」

        **意思是**：現在第一線多半用免疫組合，**但「免疫組合失敗後該用什麼」目前沒有第三期多區域 RCT**——只有 6 個二期試驗和真實世界資料。

        **原文的建議**：**優先考慮臨床試驗**；不然就在 CUSE 架構下，**優先保住肝功能、耐受度**。

        💡 **對個管師的意義**：病人問「這個藥失敗了下一個是什麼」——**很可能真的沒有標準答案**。不要假裝有。

    > **第二線依「第一線用了什麼」、疾病反應、肝功能、AFP、免疫治療禁忌及健保條件選擇——不是可互換的藥物清單。**

    💡 **個管師要記錄的是**：**第一線用了什麼、用多久、為什麼停**（進展？副作用？）——**醫師決定第二線時需要這些**。

### D 期（終末期）

- **支持與緩和照護為主**：症狀控制（腹水、肝性腦病、疼痛）
- 🔴 **但要先確認**：ECOG 不好是**腫瘤**、**肝衰竭**還是**其他共病**造成？**肝功能衰竭但腫瘤符合條件者，仍應由移植團隊評估**（見 [BCLC 表下方警示](#bclc-分期巴塞隆納臨床肝癌分期)）
- [E 進階：安寧轉介](E_advanced.md)

## 四、本癌別特殊注意事項

| 重點 | 說明 |
|------|------|
| **肝功能與肝臟儲備** | **完整評估**——Child-Pugh 是共通工具之一，另依情況評估 **ALBI、MELD、門脈高壓、腹水/肝性腦病、預估殘餘肝功能**。影響**每一個**治療決策 |
| 🔴 **病毒性肝炎** | **HBV 與 HCV 分開處理——邏輯完全不同**，見下方 |
| **AFP 追蹤** | 治療前基準、治療中每 1-3 個月、急遽上升警示。**30-40% 病人 AFP 不會升**，正常不能排除 |
| **多種治療選項** | 手術、消融、TACE、**TARE、SBRT、HAIC**、標靶、免疫——個管師要認得（見 [三、局部治療](#局部治療不是只有手術rfatace)）|
| **戒酒衛教** | 見 [FAQ](#q-病人問我可以喝酒嗎) |
| **食道靜脈瘤** | **兩種用途要分清楚**（肝硬化照護 vs bevacizumab 前），見 [二、必要檢查](#必要檢查項目) |

### 🔴 HBV 與 HCV：不要寫成「B/C 肝抗病毒治療」

**這是本檔最常被寫錯的地方。兩者的治療邏輯完全不同：**

| | **B 型肝炎（HBV）** | **C 型肝炎（HCV）** |
|---|---|---|
| **藥物** | 核苷（酸）類抗病毒藥 | **DAA**（直接抗病毒藥）|
| **療程** | 🔴 **通常需長期持續** | 🔴 **有限期療程**（不是終身吃藥）|
| **停藥** | **已在服藥者通常不應自行停藥** | 療程結束就結束 |
| **接受抗癌治療時** | 🔴 **要評估 HBV reactivation 風險**（免疫、化療都可能誘發）| — |
| **治癒後** | — | **若已有肝硬化或肝癌病史，仍需持續 HCC 監測**（治癒 ≠ 不用追蹤）|
| **誰決定** | **肝膽科**依 HBV DNA、肝硬化與治療內容決定療程與停藥時點 | 肝膽科；**抗病毒與癌症治療的先後時序需個別協調** |

**個管師的正確做法**：

> **確認 HBV／HCV 感染狀態及病毒量，轉介肝膽科評估抗病毒治療。**
> **HBV 用藥通常需長期持續並避免自行停藥；HCV 多採有限期 DAA 療程，治癒後仍依肝硬化與 HCC 風險持續監測。**

⚠️ **不要跟病人說「B/C 肝都要一直吃藥」**——**HCV 病人聽了會以為要吃一輩子**。

## 六、個管照護重點

### 收案 Checklist

> 🔴 **前兩項最容易錯**——**確認真的是 HCC**（不是膽管癌也不是肝轉移）、**確認診斷是怎麼來的**（影像 vs 病理）。

| 4 | 🚩 **有無門靜脈／肝靜脈侵犯？** | 大血管侵犯 = BCLC C；也影響 HAIC／放療的考量 | ☐ |
| 5 | **有無淋巴結或肝外轉移？** | | ☐ |
| 6 | **BCLC、ECOG、Child-Pugh／ALBI** | | ☐ |
| 7 | **腹水、肝性腦病、門脈高壓、食道靜脈瘤** | 影響治療可行性；**bevacizumab 前要看靜脈瘤** | ☐ |
| 8 | 🔴 **HBV 與 HCV 狀態「分開」記錄，各自的抗病毒計畫是什麼？** | **兩者處理邏輯完全不同**（見 [四](#-hbv-與-hcv不要寫成bc-肝抗病毒治療)）| ☐ |
| 9 | **MDT 討論了哪些選項？**（切除／消融／TACE／**TARE**／**RT**／移植／全身治療）| **不要預設只有那幾種**——BCLC 2026 已納入 SBRT、TARE | ☐ |
| 10 | **AFP、肝功能基準值** | 沒基準值之後比不出來 | ☐ |
| 11 | **飲酒史** | 戒酒衛教時機；**評估有無酒精依賴／戒斷風險** | ☐ |

### 🚩 治療期間紅旗：什麼情況要立即通報

| 情況 | 個管師動作 | 為什麼 |
|------|-----------|--------|
| **TACE／消融後高燒持續、畏寒、疼痛惡化** | **排除感染、肝膿瘍或其他併發症** | 栓塞後症候群通常 1 週內緩解——**持續惡化就不是它** |
| 🔴 **黃疸快速惡化、腹水增加、意識改變** | **立即通報，評估肝功能失代償** | 肝癌病人隨時可能失代償 |
| 🔴 **吐血、黑便、頭暈** | **緊急評估消化道／靜脈瘤出血** | 門脈高壓 + 靜脈瘤 = 大出血風險 |
| **免疫治療中腹瀉、喘、黃疸或極度疲倦** | **評估 irAE 並立即回報** | **黃疸在肝癌病人身上很容易被當成疾病進展**而漏掉免疫性肝炎 |
| **Bevacizumab 中出血、蛋白尿、血壓明顯升高** | **立即回報** | |
| **Lenvatinib／sorafenib 手足症候群影響行走** | **儘早處理，避免病人自行停藥** | 這是最常見的自行停藥原因 |
| 🔴 **新發腹痛 + 肝功能急遽惡化** | **排除腫瘤破裂、血栓或治療相關損傷** | **肝癌破裂是急症** |

### 治療期間照護

- **手術期**：傷口照護、肝功能監測（術後 2-4 週可能短暫惡化）
- **消融／TACE**：發燒（**栓塞後症候群**）、腹痛、肝功能短期波動屬正常——**但要能區分嚴重併發症**（見紅旗表）
- **TARE／SBRT**：依治療方式各有注意事項，**跟放腫／核醫團隊確認衛教重點**
- **標靶（Lenvatinib／Sorafenib）**：高血壓、手足症候群、腹瀉、疲倦
- **免疫 + 抗 VEGF（Atezo + Bev）**：irAE 警訊（喘、皮疹、腹瀉、**黃疸**）+ Bev 出血風險

!!! danger "🔴 肝硬化病人的 irAE：不能照抄非肝硬化族群的處理方式"
    **BCLC 2026 特別強調這一點**：

    > **原文**：在肝硬化病人身上，irAE 與**非免疫相關原因**的**鑑別診斷要謹慎**，並據此**謹慎、合理地使用類固醇**。**把非肝硬化族群的建議直接外推，可能增加失代償或細菌感染的風險。**

    **對個管師的意義**：

    | | |
    |---|---|
    | 🔍 **黃疸、腹水、意識改變** | 在肝癌病人身上，**可能是 irAE、也可能是肝硬化本身惡化**——**兩者處理完全相反**（一個要類固醇、一個不能）|
    | 📞 **你的任務** | **回報得夠具體**：什麼時候開始、跟上次比變化多少、有沒有其他症狀——**醫師需要這些才能鑑別** |
    | ⚠️ **不要自己判斷** | 「這應該是免疫副作用吧」——**這句話個管師不能說** |

    💡 **原文還提到特殊族群**（HIV、等待移植者、洗腎者）**證據有限、無法給普遍建議**——遇到這些個案，一律回 MDT。

!!! info "📌 BCLC 2026 把「專科護理師」明確寫進多專科團隊"
    **原文的 MTB（multidisciplinary tumour board）組成**包含：診斷與介入放射、肝膽科、腫瘤內科與放腫、外科、病理、核醫、分子生物、**specialized nursing（專科護理）**、緩和醫療、營養師、社工——**免疫治療時代還要加 irAE 專家**。

    > **原文**：「**Specialised oncology nurses play a pivotal role in patient teaching, monitoring, and care coordination.**」（專科腫瘤護理師在**病人衛教、監測與照護協調**上扮演關鍵角色）

    💡 **這不是客套話**——BCLC 2026 的參考文獻裡有一篇專門講「the role of nurses according to BCLC approach」。**你在這個架構裡是有位置的。**

### 追蹤期

!!! warning "⚠️ 沒有一套追蹤時程可以套用所有治療"
    **切除後／消融後／TACE 後／TARE 後／SBRT 後／系統性治療中／肝移植後——影像時點與判讀方式都不一樣。**

    > **追蹤時程依治療方式及醫師計畫執行。個管師應記錄「下一次動態影像、AFP、肝功能、回診日期」，確認是否完成。**

!!! danger "🔴 局部治療的療效判讀不是看腫瘤有沒有變小"
    **TACE／消融後的評估要看「viable tumor（存活腫瘤）」——也就是還有沒有動脈期增強的區域，以及有沒有新病灶。**

    **不是只看腫瘤直徑。** 一顆 TACE 後完全壞死的腫瘤，尺寸可能一點都沒變小——**但它已經沒有活性了**。

    ⚠️ **正式反應由影像科與主治醫師判定**——個管師看到報告寫「大小無變化」**不要跟病人說「沒效」**。

- **B 肝抗病毒**：通常長期持續（見 [四](#-hbv-與-hcv不要寫成bc-肝抗病毒治療)）
- **C 肝 DAA 治癒後**：**仍需持續 HCC 監測**（有肝硬化或肝癌病史者）

## 七、常見問題與處理

### Q: 病人問「為什麼我不能開刀？」

A: 肝癌能否手術**不只看腫瘤**——還要看：(1) **肝功能與肝臟儲備**能不能承受切除 (2) **殘餘肝體積**夠不夠 (3) 有沒有**臨床顯著門脈高壓** (4) 多發性或血管侵犯。

💡 **許多病人是因為肝硬化嚴重而不能開刀，不是腫瘤太大**——這句話對病人很重要，他們常以為「不能開 = 太嚴重」。

⚠️ **不能開刀不等於沒得治**——現在有消融、TACE、**TARE、SBRT**、全身治療等多種選項。

### Q: 病人是 B 肝帶原，治療肝癌中要不要繼續吃抗病毒藥？

A: **若病人已在服用 HBV 抗病毒藥，不得自行停藥。**

**但完整的說法是**：

> **是否需要開始、要持續多久、如何監測，由肝膽科依病毒量、肝功能與抗癌治療內容決定。**

**為什麼重要**：化療、TACE、免疫治療都可能誘發 **HBV reactivation**，嚴重時會猛爆性肝炎。

⚠️ **這題不要跟 C 肝混講**——**C 肝的 DAA 是有限期療程，不是終身吃藥**（見 [四](#-hbv-與-hcv不要寫成bc-肝抗病毒治療)）。病人問這題時**先確認他是 B 肝還是 C 肝**。

### Q: 病人問「TACE 做完發燒、肚子痛，是不是失敗了？」

A: 這多半是**栓塞後症候群**（post-embolization syndrome）——發燒、腹痛、噁心、ALT/AST 短期上升，**多數 1 週內緩解**，是正常反應、不是治療失敗。

🚩 **但要能區分**：**持續高燒、畏寒、疼痛惡化 → 要排除感染、肝膿瘍或其他併發症**（見[紅旗表](#-治療期間紅旗什麼情況要立即通報)）。**不要因為「這是正常反應」就都不通報。**

### Q: 病人問「我可以喝酒嗎？」

A: **建議完全停止飲酒**——酒精可能進一步損害肝功能並增加治療風險。

**但不要只用命令式回答。**

> 💡 **若病人有酒精依賴或戒斷風險，應協助轉介戒酒與身心醫療資源。** 對酒精性肝病的病人，「不要喝」講一百次也沒用——**他需要的是幫助，不是禁令**。突然完全戒斷對重度依賴者甚至有生命危險。

**個管師實務**：先問「你現在大概多久喝一次、喝多少？」——**問得出實情才知道要不要轉介**。

### Q: 病人問「我還能活多久？」

A: **不要給數字。** 處理方式見 [C1 同題](C1_lung-cancer.md#q-病人問我還能活多久)——先問他為什麼想知道，通常底下有具體的事；把那件事帶回去給醫師。

⚠️ **本檔 [BCLC 表的「預期中位存活」欄](#bclc-分期巴塞隆納臨床肝癌分期)是給你建立量級感的，不是給病人的預後。**

**肝癌特別容易講錯的地方**：

| 陷阱 | 為什麼 |
|------|--------|
| 🔴 **肝癌的預後由「兩件事」決定** | **腫瘤 + 肝功能**。同樣是 B 期，ALBI grade 1 跟 grade 3 差很多——**只看期別會講錯** |
| 🔴 **「D 期 < 1 年」不等於「這個病人 < 1 年」** | 原文自己說 BSC 這群人**很異質**：有些是早期但因共病或病人選擇而保守處理。**嚴格 D 期中位 < 3 個月，但整群人 < 12 個月** |
| 🔼 **接續治療可以走很遠** | 原文：及時接下一線可**遠超中位數**——但「**能接續治療」本身就是預後好的指標**，不是接續策略的功勞 |

### Q: 病人問「我可以換肝嗎？」

A: **Milan 準則是常用的基本評估標準之一，但不是唯一的門檻。**

**Milan 準則**：單一腫瘤 ≤ 5 cm，**或** ≤ 3 顆且每顆 ≤ 3 cm；**無**大血管侵犯；**無**肝外轉移。

**但實際能否接受移植，還要看**：

| 因素 | 說明 |
|------|---|
| **肝功能** | |
| **血管侵犯、肝外轉移** | |
| 🔴 **AFP** | **原文：AFP > 1,000 ng/ml 是廣泛認定的移植禁忌**——**不論腫瘤負荷**，因為移植後復發風險太高 |
| 🔑 **降期（downstaging）治療反應** | **部分病人可經降期後再評估移植**——不符合 Milan **不代表永遠不行**。**XXL 隨機試驗**：成功降期後移植 vs 最佳替代治療，**5 年存活 77.5% vs 31.2%** |
| **捐贈者** | 台灣等地捐贈者不足時，**活體捐贈**可緩解——但要權衡**捐贈者風險**與社會效益 |
| **移植中心規範** | **各中心與法規採用的條件可能不同**；部分中心用 **Extended criteria**（含大小 + AFP）|

> ℹ️ **關於「降期」的常見誤解**：原文特別澄清——大家講的「**neoadjuvant（前導性）治療**」在 HCC 其實多半是**降期或橋接治療**。而「**先做全身治療再移植**」在 BCLC 2026 被歸類為「**可考慮但未經證實的替代序列**」——**不要跟病人說「先打免疫再換肝」是標準做法**。

> **正確做法：轉介移植團隊評估。**

⚠️ **不要跟病人說「你不符合米蘭準則所以不能換肝」**——這可能是錯的，而且很傷。**也不要說「台灣等候時間比較短」**——這需要正式統計佐證，本手冊未查證。
