# T2 頸部淋巴 Level 圖譜（互動教材）

把頸部淋巴外科 Level I–VII 畫成可點選的圖，並整理頭頸癌最容易混淆的三套 N 分期（口腔／喉／下咽、p16+ 口咽、鼻咽）。適合接頭頸癌個案、要看懂「Level IIa、IB」與頸部清除範圍的個管師。

[開啟互動圖譜](head-neck-levels/index.html){ .md-button .md-button--primary }

## 教材內容

- **互動圖譜**：點選各 Level，看邊界與英文原文定義
- **Level 速查**：I–VII 一覽表
- **三套 N 分期**：常見黏膜頭頸癌各部位用的 N 分期與版本差異
- **個管實務對照**：病理報告與癌登填報時常見的寫法
- **試試看**：自我練習題
